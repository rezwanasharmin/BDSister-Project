# BDSisters.org — Collaborative Sisterhood Ecosystem

A dignified, member-based online platform connecting verified personal profiles, women-owned halal businesses, safe discussion forums, and skill exchange—anchored under the unified umbrella of **Muhsina Organization**.

## 🌟 Key Features

- **Halal E-Commerce Marketplace (Shop with Us):** Buy directly from verified Muslim sisters and trusted brands with strict fair-pricing policies, member discounts, and wholesale channels.
- **Unified Sisterhood Wings:** Integration with Circle of Parents (CoP), The Sacred Path Publications (TSPP), Muhsina Intellectual Dialogue & Journalism (MIDJ), and The Hut Halal Network.
- **Sister Profiles & Directory:** Verified profiles with field-level privacy (contact details private by default), district-level geolocation, and Islamic vetting.
- **Safe Sisterhood Forums:** Vetted community discussion circles covering faith, family, parenting, entrepreneurship, and skill exchange.
- **Resource Library & Events:** Educational guides, downloadable kits, live workshops, and sisterhood circles.

## 🎨 Tech Stack & Design System

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **UI Library:** React 19, Tailwind CSS
- **Animations:** Framer Motion (Smooth scroll reveal & dynamic filtering)
- **Icons:** Lucide React
- **Brand Palette:**
  - Dark Forest Green: `#123524`
  - Olive Green: `#3E7B27`
  - Soft Meadow Green: `#85A947`
  - Warm Parchment Sand: `#EFE3C2`
  - Light Background: `#FAF7EF`

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- pnpm (recommended) or npm/yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/rezwanasharmin/BDSister-Project.git

# Navigate to project directory
cd BDSister-Project

# Install dependencies
pnpm install

# Run development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
